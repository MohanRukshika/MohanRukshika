## 🚀 Selected projects

### 🛍️ Applix Furniture

I built a MERN storefront where shoppers can search for furniture, manage their cart, place an order, and see their order history. Admins manage the product catalog and review incoming orders.

- Added Google sign-in and an email OTP flow for password resets.
- Used JWT authentication and Express middleware to protect admin routes.
- Modeled products and orders with Mongoose. Deployed the React frontend on Vercel and the Express backend on Render.

[Explore the live store →](https://applix-furnitures.vercel.app)

### 🤖 AI Chatbot

I connected a Java chat interface to a Llama model through the Groq API. This was my first-hand experience taking a user's message, sending it to a language model, and displaying the reply in the application.

### 📚 Library Management System
